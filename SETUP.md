# Getting the game running

This guide takes you from a fresh computer to playing OPERATION BLACKOUT. If an AI
assistant is helping you, just show it this file — everything it needs is here.

## What this is

A browser-based first-person shooter. There is no installer and no build step — a tiny
Node.js server hosts the files, and the game runs entirely in your web browser. All
graphics and sound are generated by code when the page loads, so the download is small.

## Prerequisites

- **Node.js 18 or newer** (comes with `npm`). Check with `node --version`.
  - Windows/Mac: download from <https://nodejs.org> (the LTS version is fine)
  - Ubuntu/Debian: `sudo apt install nodejs npm`
- **A desktop browser** — Chrome, Edge, or Firefox. It needs WebGL, which any recent
  browser on a desktop or laptop has. Phones are not supported (mouse + keyboard game).
- **Git** to clone the repository (or use GitHub's "Download ZIP" button instead).

## Install and run

```bash
git clone https://github.com/abovespec/OperationBlackout.git
cd OperationBlackout
npm install        # one time, installs the dev dependencies (~a few seconds)
npm start          # starts the server
```

Then open **http://localhost:8123** in your browser.

In the menu: pick a difficulty (**start with RECRUIT or REGULAR** — the top tiers are
brutal), pick a map and a loadout, and press **DEPLOY**. Click the screen once so the
game captures your mouse.

To stop the server press `Ctrl+C` in the terminal. To play again later you only need
`npm start` — the install is a one-time step.

## Controls

| | |
|---|---|
| `WASD` | move |
| Mouse | look / aim |
| Left mouse | fire |
| Right mouse | scope (sniper only in the default ruleset) |
| `SHIFT` | slow silent walk (enemies can't hear you) |
| `CTRL` / `C` | crouch |
| `SPACE` | jump |
| `R` | reload (guns also auto-reload when empty) |
| `E` | pick up a weapon dropped by a dead enemy |
| `1` / `2` / `3` / `4` | rifle / pistol / knife / grenade |
| `G` | quick grenade |
| `Q` | last weapon |
| `TAB` | scoreboard |
| `ESC` | pause / release the mouse |

Tips: stand still to shoot accurately — running fire barely hits anything. The knife
kills instantly from behind. Dead enemies drop their guns; press `E` to grab one when
you're out of ammo.

## Troubleshooting

- **`node: command not found`** — Node.js isn't installed or isn't on your PATH.
  Install it from <https://nodejs.org> and reopen the terminal.
- **Port already in use** — something else is on 8123. Either close it, or edit the
  `PORT` value in `tools/serve.mjs`.
- **Black screen / won't load** — make sure you're on a desktop browser with WebGL
  enabled (visit `chrome://gpu` in Chrome to check). Try Chrome if Firefox misbehaves.
- **Low framerate** — set Quality to LOW in the menu; it skips the whole
  post-processing chain.
- **Mouse won't lock** — click once inside the game view; browsers require a click
  before they hand over the pointer.

## For AI assistants

- `npm start` runs `node tools/serve.mjs`, a dependency-free static file server on
  port 8123. There is no build, bundler, or transpile step; `src/` is plain ES modules
  loaded directly by the browser.
- The only runtime dependency is `three` (vendored via npm); `playwright` is a dev
  dependency used by the test tools in `tools/` and is not needed to play.
- `README.md` documents the gameplay systems, architecture, and the headless
  test/screenshot tooling in detail.
